# Security Policy

## Reporting a vulnerability

Please do not disclose a suspected vulnerability publicly before a fix is available.

Contact: **ildrm@hotmail.com**

Include, where possible:

- affected AegisGuard version,
- WordPress and PHP versions,
- reproduction steps,
- required role/authentication level,
- impact,
- proof of concept that avoids destructive activity,
- suggested mitigation.

Do not send production passwords, API keys, authentication cookies, private customer data, or complete database dumps.

## Security expectations

AegisGuard is defense-in-depth software. It cannot compensate for a compromised operating system, stolen hosting control-panel credentials, malicious server administrators, vulnerable software outside WordPress, or attacks that never reach WordPress because they occur at the network/hosting layer.
